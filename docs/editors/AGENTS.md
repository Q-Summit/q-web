# docs/editors AGENTS.md

Editor handbook for division members (non-developers). Extends [`../AGENTS.md`](../AGENTS.md). Human index: [`README.md`](README.md) (`seo.md`, `llms.md`).

Schema / surfaces: [`../architecture/08-concepts.md`](../architecture/08-concepts.md). Schema changes that affect editor docs update this folder in the same PR.

## ALWAYS

- Write for someone who only knows the Payload admin UI in a browser.
- Name Payload labels exactly as the admin shows them.
- Keep SEO vs AI-assistants split (`seo.md` vs `llms.md`).

## NEVER

- Use repo jargon (PR, CI, markdown, branch, wrangler, monorepo) except when telling someone to contact maintainers.
- Tell editors to edit files under `apps/` or hand-edit `/llms.txt`.
- Invent admin screens or publish steps the schema does not implement.
- Put maintainer setup here (→ [`../dev/`](../dev/)).
